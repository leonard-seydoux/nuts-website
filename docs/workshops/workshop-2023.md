# Journées NuTS 2023

![Journées NuTS 2023](../images/2023-workshop-group-photo.jpg)

## Présentation

Les ressources de calcul et l'apprentissage machine : deux jours de présentations, puis deux jours de travaux pratiques (Jupyter, Python) sur les GPU A100 du [mésocentre GLiCID](http://www.glicid.fr/), et une session posters.

## Lieu

Bâtiment Darwin, 3-9 rue Raphaël Dubois, 69100 Villeurbanne (campus de la Doua).
